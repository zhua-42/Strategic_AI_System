# 网站能力评估（局部优化后）

评估范围：`app.py`、`report_export.py`、`leader_compare.py`、`product_features.py` 及当前部署页面。结论是按现有数据源和导出能力判断，不能把“模型可以生成文字”当作“结果具备投行级数据依据”。

## 已具备

- A 股行业/公司研究流水线：规划、数据检索、财务分析、风险、证据链和报告生成。
- 基础两阶段 DCF：可输入 FCF、增长率、WACC、永续增长率和预测年限，输出预测现金流、终值及终值现值占比。
- Plotly 页面图表，以及 matplotlib 兜底的 Word/PPT 图表导出。
- PDF、XLSX、CSV 上传解析；上传材料可以作为资料缺口补充。
- 行业集中度、财务趋势、杜邦、风险雷达和龙头横向比较（主要面向 A 股）。

## 四项任务的可行性

| 任务 | 当前状态 | 原因 |
| --- | --- | --- |

## 仍需补齐的生产级能力

1. 增加美股/交易数据适配层：价格、股本、债务、现金、收入、毛利、ARR/NRR、共识预期和来源日期。
2. 将用户上传的 10-K/10-Q、年报和共识数据与公司代码、报告期、币种自动校验。
3. 增加正式 M&A 审阅流程：匿名化字段检查、管理层/客户信息权限和买方名单人工复核。
4. 为 Meta/SNOW 建立专用数据检查：报告期、来源 URL、抓取时间、共识口径和单位换算。

在这些数据与模板接入之前，网站适合做研究初稿、图表和资料缺口审查，不适合直接作为出售材料或投资委员会最终底稿。

## 本次局部优化

- RAG 依赖改为懒加载，默认先进入关键词检索，避免首次唤醒同步加载 Torch/Chroma。
- 所有页面 Plotly 图表统一主题和下载配置；报告 JSON 会清洗 `NaN`/`Infinity`，单图渲染异常不会阻断整页。
- DCF 工具增加预测年限校验，并返回预测现金流、终值、现值和终值占比。
- 密钥状态提示不再显示长度和前缀。
- 新增顶部工作台页面：交易材料与估值、可比公司分析、DCF 情景模型、财报更新和产业链地图；原 AI 研究报告页面保留。
- 新增中国大陆优先、全球公开披露、用户上传优先三种来源策略；新闻抓取返回逐来源成功状态。
- 产业链地图保留原 3D 图，并新增 2D 可读视图、数据质量标记和动态刷新状态。
- 可比公司页面支持 CSV/XLSX、公开网页 URL 和手工编辑三种输入方式；网页读取失败时仍保留表格编辑和本地工作流。
