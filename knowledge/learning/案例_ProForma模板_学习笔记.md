# 中信证券 Pro Forma 财务报表模板学习笔记

来源：案例_中信证券_ProForma财务报表模板.pdf（用户提供）。

## 编制基础

- 历史备考模拟：假设收购、剥离或重组在报告期期初完成，追溯重述历史合并报表。
- 未来盈利预测模拟：基于经营规划与行业趋势预测 3/5 年，用于 DCF、盈利预测和披露。
- 基准采用公司经审计合并财务报表；会计政策与会计估计遵循企业会计准则。
- 所有调整分录、核心假设、来源和勾稽关系留痕。

## 核心假设字段

营业收入增速、毛利率、销售/管理/研发费用率、DSO、存货周转天数、DPO、CAPEX、有效税率、汇率、融资/分红及并购调整。

## 四张主表与勾稽逻辑

1. 合并模拟利润表：营业收入、营业成本、税费、销售/管理/研发/财务费用、营业利润、利润总额、所得税、净利润、归母净利润、少数股东损益、EBITDA。
2. 合并模拟资产负债表：货币资金、交易性金融资产、应收、存货、预付、固定资产、在建工程、无形资产、商誉、借款、应付、合同负债、权益及总计；资产总计 = 负债合计 + 所有者权益合计。
3. 合并模拟现金流量表（间接法）：净利润、折旧摊销、利息、营运资本变动、CAPEX、借款、偿债、分红利息、期末现金；期末现金必须与资产负债表货币资金一致。
4. 合并模拟所有者权益变动表：期初权益、净利润、增发/回购、盈余公积、分红、期末权益；期末权益必须与资产负债表一致。

## 交付前校验

资产负债表平衡、现金流量表期末现金勾稽、净利润与未分配利润勾稽、权益合计勾稽、折旧摊销回加、营运资本变动、所得税费用与应交税费变动。

## 网站实现约束

PDF 报告附录采用上述四张表的统一字段和勾稽说明；用户输入或上传数据优先，缺失项显示“待补充/待核验”，不把示例假设标记为真实事实。
