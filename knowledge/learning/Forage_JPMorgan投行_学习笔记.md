# JPMorgan 投行 Job Simulation（并购交易）学习笔记

**来源**：Forage JPMorgan Chase Investment Banking Job Simulation + 6 个公开 GitHub 仓库（soumyakantabera、raunakkun 等，见 `Forage_Answers\JPMorgan_Investment_Banking\00_说明.md`）
**类型**：Forage 模拟练习
**一句话价值**：通过"啤酒公司收购案"完整走一遍并购顾问（M&A Analyst）工作流——目标筛选、公司简介、DCF 估值、危机下的投资建议，是投行求职必练的经典案例。

## 核心知识点

- **案例设定**：作为摩根大通并购团队分析师，为啤酒公司 WorldWide Brewing Co.（CEO Carlos）寻找收购标的，候选为香港饮料公司 HappyHour Co.。
- **任务结构（4 个任务 = 并购交易全生命周期）**：
  1. **寻找并购目标**：审阅 5 家潜在目标的电话会议记录，从战略契合度、股权结构、财务状况、交易复杂度筛选，写推荐邮件（首选 HappyHour）。
  2. **目标公司信息与拍卖流程**：制作一页式 2-pager 简报——公司概况（股权结构、FY17–FY20E 财务、初步估值区间 EV/EBITDA 10.0×–11.5×）+ 两阶段拍卖流程（NDA/管理层演示 → 意向性报价 → 最终报价）。
  3. **DCF 建模**：用公司 5 年预测（FY21–FY25），WACC 折现 + 永续增长法（终值增长率 1.0%）算出企业价值、股权价值、股价与收购溢价，做 PPT 汇报。
  4. **投资建议**：突发火灾后调整假设（FY21 收入 $1,256mm→$1,100mm、毛利率降至 50.0%），重跑 DCF；面对竞争对手 DownUnder Beverages 的 $650mm+ 有约束力报价，给出是否继续竞价的建议。
- **标准做法**：投行工作流 = 目标筛选（定性）→ 公司简介（信息呈现）→ 估值建模（定量）→ 情景应变（动态更新模型）。

## 学习要点

1. 目标筛选要建立**多维打分框架**（战略、股权、财务、复杂度），不能只看单一指标。
2. 2-pager 是投行核心交付物：信息密度高、一页讲清公司全貌，版式可直接复用官方模板。
3. DCF 建模要掌握：WACC 折现、终值（Gordon Growth）、企业价值→股权价值→每股价格→溢价的完整换算链条。
4. 模型要"可更新"：火灾这种突发情景下，只改两个假设（收入、毛利率）就要能快速重算全表。
5. 投资建议要结合**竞争形势**（对手出价）+ 自身估值（溢价空间）综合判断，而不是只看模型数字。
6. 用"Model Answer"（raunakkun 仓库的官方参考答案 PDF）对照自己的邮件和 PPT，学习专业表达。
7. 各仓库财务数字一致性好（EV $803mm → $738.5mm、溢价 118.8% → 99.1%），可互为校验。

## 实践建议

1. 用 Excel 从零搭一个 DCF 模板，逐步填入预测、WACC、终值，跑通三张表联动。
2. 练习"假设变化→重算→更新结论"的情景分析（如火灾、对手出价），并写一封 300 字内的建议邮件。
3. 对照官方 Model Answer 逐句改自己的邮件/PPT，学投行措辞（结论先行、数字支撑）。

## 关键数据/答案

- 初始估值：EV/EBITDA 10.0×–11.5×；火灾前 EV ≈ $803mm（溢价约 118.8%）
- 火灾后修订：FY21 收入 $1,100mm、毛利率 50% → EV ≈ **$738.5mm**，约 **328.6c/股、99% 溢价**
- 终值增长率 1.0%；对手 DownUnder Beverages 报价 $650mm+
