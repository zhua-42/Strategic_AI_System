# PwC 美国管理咨询 Job Simulation（并购与战略）学习笔记

**来源**：Forage PwC US Management Consulting Job Simulation 公开仓库 README 与交付物（PwC-US-Management-Consulting-Job-Simulation、PwC-Management-Consulting-Simulation 等；本目录无 00_说明.md，以下基于参与者 README 整理）
**类型**：Forage 模拟练习
**一句话价值**：以管理咨询顾问视角练三件套——公司业务摘要、分拆访谈提纲、并购协同 PPT，覆盖咨询项目"案头研究→尽调问题设计→定性分析"的核心套路。

## 核心知识点

- **任务结构（3 个任务，围绕一条并购故事线）**：
  1. **Business Summary（业务摘要）**：为上市公司（如 Apple）撰写结构化业务摘要：公司概况、财务表现（FY2024 营收 $391.0B 及分部拆分）、产品与服务分析（iPhone 占 46%、Services 占 23%）、地域收入分布、竞争地位、战略举措、风险因素、未来展望。
  2. **Divestiture Interview Guide（分拆访谈提纲）**：为 CFO 会议设计 15–20 个结构化访谈问题，覆盖战略动因、财务表现、组织运营、整合依赖、客户市场、法律合规、交易执行 7 大类。
  3. **Qualitative Synergy Presentation（协同效应定性分析）**：选一个近期 M&A 交易，3 页 PPT 讲清交易概览与战略动因、收入协同（交叉销售、市场扩张）、成本协同（规模效应、冗余消除）。
- **标准做法**：咨询交付 = 案头研究（10-K/10-Q、投资者材料、行业报告）→ 结构化框架（按主题分类）→ 提炼关键信息供高管消费 → 专业格式输出。Task 3 尤其强调"2–3 篇文章、15 分钟内快速研究 + 4–5 个关键协同点"的快速产出能力。

## 学习要点

1. 业务摘要的"高管消费"导向：信息按逻辑分类、数据验证、结论清晰，一页讲清公司全貌。
2. 访谈提纲是尽调基本功：按主题分组设计问题，问题要有优先级、可追问、留记录空间。
3. 协同效应要分**收入协同**与**成本协同**两类分析，且落到"怎么赚钱、怎么省钱"的具体机制。
4. 快速研究能力：限时用少量资料提炼关键点，是咨询面试常考能力。
5. 幻灯片设计原则：行动导向标题（Action-oriented titles）、清晰叙事流、专业排版。
6. 从"数字到故事"：财务建模（如航空协同模型：EBIT 从 5% 提升到 14.95%–23.30% 区间）与定性分析结合，结论才有说服力。
7. 技能迁移：10-K 拆解能力、M&A 战略思维、18 问访谈框架均可复用到其他咨询案例。

## 实践建议

1. 用任意上市公司年报，30 分钟写一页"业务摘要"，练信息取舍与结构化。
2. 为一个假设的分拆交易写 15 个分主题访谈问题，注意覆盖"整合依赖"这类容易被忽略的维度。
3. 找一篇并购新闻，15 分钟内列出 4–5 个协同点并做成 3 页 PPT，练快速产出。

## 关键数据/答案

- Apple 示例：FY2024 营收 $391.0B；iPhone 占 46%、Services 占 23%
- 航空协同模型示例：目标营收 $100M，保守协同 $9.95M / 激进 $18.3M；EBIT 从 5% 提升至 14.95%–23.30%；协同来源：G&A、燃油、飞机租赁、维护、软件授权
- Microsoft 案例：FY2025 营收 $281.7B（+15%）、EBITDA 利润率 57.7%；Activision $75.4B 收购，协同看点：移动游戏（King/Candy Crush 年收入 $2.5B+）、云与 AI
